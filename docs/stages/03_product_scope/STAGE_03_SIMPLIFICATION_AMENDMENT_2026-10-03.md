# Stage 3 Simplification Amendment — 2026-10-03

**Status:** Owner authorized  
**Scope:** Narrow Stage 3 simplification only  
**Does not reopen:** Stages 0–2, concept selection, safety model, human authority, privacy, or evaluation architecture

## Why this amendment exists

The closed Stage 3 route remained substantively correct but over-specified two implementation details:

1. intermittent/shared/assisted smartphone access had been converted into a rigid weekend/daughter/on-slope choreography;
2. Lugisu human validation risked becoming a build-blocking dependency rather than a localization-claim gate.

The owner directed a simplification before empirical model development so that no evidence is burned.

## Controlling changes

- **Value:** RoyaCheck allocates scarce human-review attention more effectively; it does not accelerate extension access or create extension capacity.
- **Device access:** intermittent/shared/assisted access is the invariant. Daughter/weekend assistance is a valid demo example, not the only valid path.
- **Capture:** capture/select a current eligible coffee-leaf image when the household smartphone and needed assistance are available. No mandatory original-plant return, weekend/on-slope session, attached-leaf workflow, backing card, preservation, transport, or detachment recommendation.
- **Timing:** intermittent access may cause delay, but delay is not a product requirement. The model evaluates only the current captured image.
- **Handoff:** remains user initiated, in person, on device, with no autonomous sending or new integration.
- **Localization:** Lugisu remains the current prototype direction. Human validation is required for a claim of validated localized usability, not for technical MVP progress. Without a qualified validator by the cutoff, Lugisu may remain only as an explicitly unvalidated prototype draft with English available.
- **Routing:** `visible rust → Review first`, `not sure → Retake or request review`, `no visible rust → Record and monitor` remain unchanged.
- **Non-solutions:** yield-cause diagnosis, price bargaining, registry creation, extension-capacity creation, and treatment selection remain outside scope.

## Audit handling

Historical Stage 3 Claude audit and confirmation artifacts remain unchanged as historical evidence.

- human-final authority;

Under the owner-approved Stage 3 Tier B process, no new multi-round Stage 3 audit cycle is required for this assumption-reducing amendment.
